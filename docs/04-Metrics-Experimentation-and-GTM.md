# 04. Metrics, Experimentation & Go-To-Market

## Overview

This document defines how LIFE OS AI would measure product success, evaluate product hypotheses through experimentation, launch to its target audience, monetize the product, and use post-launch feedback to guide future iterations.

The framework connects:

**Product Value → User Behaviour → Metrics → Experimentation → Growth → Monetization → Iteration**

---

# 1. North Star Metric

## Weekly Active Goal Achievers (WAGA)

### Definition

**Weekly Active Goal Achievers (WAGA)** is the number of unique users who complete at least one meaningful goal-related action during a given week using LIFE OS AI.

### Why This Metric Matters

WAGA measures whether users are actually making progress toward their goals rather than simply using the application.

The metric is directly connected to the core product promise of helping users:

- Improve productivity
- Build habits
- Achieve meaningful goals
- Make consistent progress

### Connection to User Value

Users use LIFE OS AI to improve productivity, build habits, and achieve meaningful goals.

WAGA therefore reflects whether the product is helping users accomplish these outcomes.

### Connection to Business Value

A higher number of active goal achievers can indicate stronger:

- Engagement
- Retention
- Product value
- Long-term growth
- Monetization potential

# 4. Experimentation Framework

## Experiment Name

**AI Daily Planner Effectiveness Test**

### Hypothesis

> Users who receive AI-generated daily plans will demonstrate higher engagement and goal completion rates than users who create plans manually.

### Control Group: Version A

Users manually create daily plans.

### Variant Group: Version B

AI automatically generates personalized daily plans.

### Target Users

New users who joined within the last 30 days.

### Primary Success Metric

**Goal Completion Rate**

### Secondary Metrics

- Daily Active Users
- Weekly Active Users
- User Satisfaction Score
- AI Recommendation Acceptance Rate

### Success Criteria

The experiment will be considered successful if the AI-generated planner improves goal completion rates by **at least 15%** compared with the control group.

### Experiment Duration

The experiment will run for:

**4 weeks**

or until both groups reach statistically significant sample sizes.

---

# 5. Experiment Decision Logic

The experiment is designed to answer a specific product question:

> Does AI-generated planning create better user outcomes than manual planning?

### If the AI Variant Wins

Potential next steps:

- Increase adoption of AI Daily Planner
- Improve AI-generated planning
- Expand personalized recommendations
- Investigate additional AI planning use cases

### If the Control Wins

Potential next steps:

- Investigate why manual planning performs better
- Analyse user feedback
- Identify weaknesses in AI-generated plans
- Improve personalization
- Retest the feature after iteration

### Product Principle

Experimentation should be used to validate product assumptions rather than assuming that an AI feature automatically creates value.

### Free Plan

- Goal Tracking
- Task Management
- Habit Tracking
- Limited AI Recommendations

### Premium Plan

**₹299/month**

Includes:

- Unlimited AI Coaching
- Advanced Weekly Insights
- Personalized Goal Plans
- Priority AI Processing

---

# 14. Why Freemium?

The freemium model is intended to:

- Reduce barriers to adoption
- Allow users to experience the core product
- Create a pathway toward premium conversion
- Monetize highly engaged users who value advanced AI capabilities

The model therefore connects product adoption with monetization without requiring users to pay before experiencing the core workflow.
